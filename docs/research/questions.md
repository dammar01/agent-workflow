# Open research questions

Each question is a separate research program; none is a roadmap commitment. No
implementation starts from a question alone: it goes through the cycle in
[CONTRACT.md](CONTRACT.md) (question, literature, synthesis, hypothesis, experiment,
decision).

Each question is a record in [questions/](questions/) (`RQ-NN`, DEC-017), with its notes
there. "Status" describes what exists in the repository today, not whether the question is
answered. "Records" lists tracked records only; drafts serving a question are named in its
notes. A record at schema version 2 names the questions it serves, and the check holds both
sides to each other (CONTRACT.md §16).

Generated from the records by `python tools/maintain/check_research.py --write-inventory`;
the check fails when it is stale.
