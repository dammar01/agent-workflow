# Research log — 2026-09-26

A summary of one research period, written at the transition from v3.7.1 to v3.7.2. It is a
fixed snapshot: the current status of every claim lives in the linked records, not here.

## The shift in the research question

```text
Before   How can agent-workflow make coding agents more efficient?

After    Under what conditions can an external harness change the division of labor
         between humans, coding agents, and repository context in a way that produces
         net engineering benefit?
```

The second question includes model capability, harness capability, user behavior, task and
repository complexity, latency, human attention, and verification.

## Project thesis

> `agent-workflow` explores whether externalizing repository exploration, evidence
> handling, and execution control from a primary coding agent can improve
> software-engineering workflows on complex real-world repositories.

## The system being studied

```text
                    CODING AGENT SYSTEM
        ┌───────────────────┼───────────────────┐
      Model              Harness              Human
   reasoning          state · control       delegation
   coding             evidence              supervision
                      orchestration         mental model
                           │
                      Environment
                      (repository)
```

The LLM is not treated as the only source of intelligence; the harness and the human's
way of delegating are part of the system.
