# v3.8.1

Rilis perbaikan atas 3.8.0, dari review branch dan wawancara pemakaian: export metrics
memeriksa nama project di semua panjang, gate tak lagi memblokir pembacaan skill, selector
terbukti berlaku lintas id di route dinamis, dan dua stamp provenance tak lagi mengklaim
yang tak terbukti. Tidak ada perubahan breaking pada konfigurasi. Hook dan skill baru aktif
setelah `install`/`upgrade`.

**Perubahan perilaku yang terasa setelah upgrade:**

- Read `~/.claude/skills/<name>.md` lolos saat gate aktif, jadi skill workflow bisa dibaca
  sebelum dispatch.
- Selector `proven` yang tercatat di route ber-id sebelum rilis ini kehilangan peringkatnya
  sampai satu run bersih membuktikannya lagi di route `:id`.
- Export yang memuat nama project pendek sebagai kata kini ditolak.
- `install --check` di project codex tak lagi melaporkan `MISSING opencode/opencode.project.json`.

## Export dan provenance (DEC-038)

- Nama project yang menyumbang data dicocokkan sebagai kata utuh di semua panjang; sebelumnya
  nama ≤2 karakter dilewati.
- Key di bawah `per_project` dan `by_project` wajib berbentuk label tool (`PA`,
  `Project AB`); nama folder di sana ditolak menurut bentuknya.
- `tool_commit` mengembalikan `null` bila `git status` gagal, alih-alih hash yang tampak
  bersih.

Detail: [docs/evaluation/metrics.md](../evaluation/metrics.md).

## Gate pre-flight (DEC-039)

Read definisi skill lolos untuk semua command delegated: path absolut tanpa `..`, `.md`, file
ada, dan path aslinya (symlink diikuti) di dalam `~/.claude/skills`. Kedua flavor hook sama.
Flavor `.ps1` membandingkan path dengan separator OS yang berjalan, jadi `pwsh` di Linux tak
lagi menolak skill yang sah (ditemukan CI Linux, direproduksi dengan pwsh 7.4 di Linux).

`graph-refresh.ps1` di bawah `pwsh` non-Windows (jalur CI, bukan instalasi: POSIX memakai
flavor `.sh`) kini memulai worker tanpa `-WindowStyle` dan dengan output dialihkan,
membaca lock rusak dengan `-ErrorAction Stop`, dan melihat `.refresh.lock` yang tersembunyi
dengan `-Force`. Sebelumnya worker tak pernah jalan dan lock setengah tertulis dianggap
ditinggalkan.
Detail: [docs/reference.md](../reference.md), "Pre-flight gate".

## `/.verify-browser` (DEC-040)

Detail: [docs/runtime-contracts.md](../runtime-contracts.md).

## Graph refresh tanpa batas waktu (DEC-042)

Worker graph-refresh menjalankan `graphify update` sampai selesai, tanpa batas waktu dan tanpa
membunuhnya; `GRAPH_REFRESH_LIMIT_S` tak lagi dibaca dan baris baru tak pernah `timeout`.
Selama graphify jalan, worker menulis ulang `beat` di `.refresh.lock` tiap 15 detik; lock
dianggap dipegang selama `beat` < 120 detik, berapa pun umurnya. Lock lama tanpa `beat` tetap
memakai aturan 15 menit. `doctor` melaporkan lock ini dan menyarankan langkah bila refresh
berjalan ≥ 1 jam atau lock-nya basi; `clean` menghapus hanya lock basi dan tak pernah
membunuh proses. graphify yang hang menahan graph sampai prosesnya dihentikan pengguna.

## Installer (DEC-041)

`install --check` di dalam workspace hanya memeriksa boundary project milik provider yang
dijalankan project, sama dengan yang dipasang `init`. Sebelumnya project codex selalu DRIFTED
karena `opencode.json` yang tak pernah dipasang perintah apa pun. Project tanpa provider
eksplisit tetap diperiksa sebagai opencode. Cek installer di `tools/e2e` kini menulis
`second_agent.json` project dari example sebelum `init`, jadi seed provider mesin tak lagi
menentukan hasilnya — dua kegagalan e2e yang dicatat di [v3.8.0](v3.8.0.md) hilang.
